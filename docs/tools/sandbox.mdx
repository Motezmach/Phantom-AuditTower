# Phantom sandbox

The sandbox is the Docker execution environment used by agents for assessment work. It keeps tool execution separate from the host and gives every run a repeatable environment.

## Use the Phantom image

The default image is:

    phantom-sandbox:1.3.0

Build it from the repository root:

    docker build -f containers/Dockerfile -t phantom-sandbox:1.3.0 .

Or use the helper script from Bash:

    bash scripts/docker.sh 1.3.0

If the image has another local tag, set:

    PHANTOM_IMAGE=your-local-image:tag

## Resource limits

Limits are optional:

    PHANTOM_SANDBOX_CPUS=2
    PHANTOM_SANDBOX_MEM_LIMIT=4g

Use limits appropriate for the host and the size of the assessment. Docker must be running before Phantom starts a scan.

## Troubleshooting the sandbox

Check that the image exists:

    docker image inspect phantom-sandbox:1.3.0

Check that Docker is reachable:

    docker info

If Phantom reports that the image is missing, build it or set PHANTOM_IMAGE to an image that exists locally.

The sandbox identity was changed for Phantom while preserving the working baseline image and tool behavior. This documentation does not claim a change to container privilege policy.
