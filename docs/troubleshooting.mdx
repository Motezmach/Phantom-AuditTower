# Troubleshooting

## First checks

From the repository root, confirm:

```text
uv --version
docker info
docker image inspect phantom-sandbox:1.3.0
```

If `uv` is not found, install it from the [uv installation guide](https://docs.astral.sh/uv/), then reopen the terminal. Start Docker Desktop before running Phantom.

## Model configuration

Check the variables in the same terminal that launches Phantom.

PowerShell:

```powershell
Get-ChildItem Env:PHANTOM_LLM
Get-ChildItem Env:LLM_API_KEY
Get-ChildItem Env:LLM_API_BASE
```

Bash:

```bash
printenv PHANTOM_LLM
printenv LLM_API_KEY
printenv LLM_API_BASE
```

For DeepSeek or another cloud provider, use the provider's exact model identifier and a current key. For Ollama, use `LLM_API_BASE` and normally omit the API key. Never paste a real key into a report, issue, or commit.

## Sandbox image

Build the local image if inspection fails:

```text
docker build -f containers/Dockerfile -t phantom-sandbox:1.3.0 .
```

If you use another image, set `PHANTOM_IMAGE` in the same terminal before launching the scan.

## Windows notes

Use PowerShell syntax for environment variables:

```powershell
$env:PHANTOM_LLM="provider/model"
$env:LLM_API_KEY="your-api-key"
```

Bash syntax such as `export ...` does not set a PowerShell variable. Python 3.12 is the supported baseline; if a local virtual environment was created with another Python version, remove and recreate it with the supported interpreter before running `uv sync`.

## Viewer and PDF

Use the exact run name printed by the scan:

```text
uv run phantom view <run-name>
```

The viewer must be started from the current checkout so it serves the matching local API and static bundle. A PDF download is available only after the run is marked finished. If the browser reports a 404 for `/api/report/pdf`, stop an older viewer process and reopen it from the current checkout.

## Interrupted scans

A disconnected model or network can leave a resumable run:

```text
uv run phantom --resume <run-name>
```

Inspect `phantom_runs/<run-name>/run.json` and `phantom.log` before deciding whether to resume. A partial run should not be treated as a completed report.

## Evidence and cleanup

Keep the run directory until the report and evidence have been copied to the approved engagement location. Never commit API keys, private target data, or generated `phantom_runs/` directories.
