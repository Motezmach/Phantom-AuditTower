# Assessment instructions

The target flag identifies the application. Additional instructions should make the engagement boundaries and test goals unambiguous.

Useful instructions include:

- Exact in-scope hosts, paths, and environments.
- Whether authenticated testing is authorized and how test credentials are provided.
- Important test accounts and their intended roles.
- Rate limits, maintenance windows, and prohibited actions.
- The business workflows that matter most.
- Evidence or report format requirements.

Keep credentials in the approved secret mechanism rather than in prompts or committed files. Do not include unrelated production data.

A clear scope lets the root agent delegate focused work and lets validators distinguish a confirmed issue from an unverified lead.
