# Scan modes

Scan modes control how much work Phantom schedules.

| Mode | Use it for |
| --- | --- |
| quick | A fast smoke test and initial attack-surface view. |
| standard | A balanced assessment for normal development checks. |
| deep | A longer assessment with broader exploration and validation. |

Start with quick when checking setup or a new local build. Use standard or deep only when the target scope, time, model budget, and rate limits allow it.

The selected mode does not replace authorization. The target and engagement instructions still define what Phantom may test.
