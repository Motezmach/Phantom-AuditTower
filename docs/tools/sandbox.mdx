# Docker sandbox

Phantom runs agent tools in a local Docker container. The default image is:

```text
phantom-sandbox:1.3.0
```

Build it from the repository root:

```bash
docker build -f containers/Dockerfile -t phantom-sandbox:1.3.0 .
```

The image is based on `kalilinux/kali-rolling`. It is independent of the LLM provider and only needs to be built or pulled once per machine.

## Privileges and boundaries

- Runtime commands run as the `pentester` user, not as root.
- `pentester` belongs to the sudo group and has passwordless sudo. The image is therefore non-root by default, but it is not a strict no-root sandbox.
- Phantom adds Docker capabilities `NET_ADMIN` and `NET_RAW`. Nmap receives the required network file capabilities during the image build.
- The container can reach the host through `host.docker.internal`, which is useful for an authorized local application.
- The run workspace is mounted at `/workspace`. Extra workspace files are mounted read-only.
- Caido is started in the container for proxy capture and normally exposes port `48080`.
- The image contains the tools and runtimes needed by the agent; the model itself runs outside the container.

## Resource limits

CPU and memory are not capped unless configured. Set limits before starting a scan:

PowerShell:

```powershell
$env:PHANTOM_SANDBOX_CPUS="2"
$env:PHANTOM_SANDBOX_MEM_LIMIT="4g"
$env:PHANTOM_SANDBOX_SHM_SIZE="1g"
$env:PHANTOM_SANDBOX_PIDS_LIMIT="512"
```

Bash:

```bash
export PHANTOM_SANDBOX_CPUS="2"
export PHANTOM_SANDBOX_MEM_LIMIT="4g"
export PHANTOM_SANDBOX_SHM_SIZE="1g"
export PHANTOM_SANDBOX_PIDS_LIMIT="512"
```

Container JSON logs are limited by default to `50m` per file and three rotated files. See [Configuration](../advanced/configuration) for all Docker-related settings.

## Lifecycle

Phantom creates the container when a scan needs a sandbox and removes it during normal cleanup. If a run is interrupted, check Docker before manually removing a container. Run artifacts remain in `phantom_runs/<run-name>/` and are separate from the image.
