# Quickstart

## Requirements

- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/)
- Docker Desktop or Docker Engine
- A cloud LLM API, or a compatible local LLM server

## Windows PowerShell

```powershell
cd audit-tower
uv sync

# Choose one provider:
$env:PHANTOM_LLM="ollama/qwen3-vl"; $env:LLM_API_BASE="http://localhost:11434"
# or
$env:PHANTOM_LLM="provider/model"; $env:LLM_API_KEY="your-api-key"

uv run phantom --target "http://demo.testfire.net/" --scan-mode quick
```

## Linux

```bash
cd audit-tower
uv sync

# Choose one provider:
export PHANTOM_LLM="ollama/qwen3-vl" LLM_API_BASE="http://localhost:11434"
# or
export PHANTOM_LLM="provider/model" LLM_API_KEY="your-api-key"

uv run phantom --target "http://demo.testfire.net/" --scan-mode quick
```

Replace the example target with an application you own or are explicitly authorized to assess.

If the default sandbox image is not available locally, build it once from the repository root:

```text
docker build -f containers/Dockerfile -t phantom-sandbox:1.3.0 .
```

For Ollama or another OpenAI-compatible local server, set `PHANTOM_LLM` and `LLM_API_BASE`; a local server normally does not need `LLM_API_KEY`.

## View and resume

After the scan, note the run name printed by Phantom:

```text
uv run phantom view <run-name>
uv run phantom --resume <run-name>
```

Runs are stored under `phantom_runs/<run-name>/`. The viewer and PDF export are local; no account or hosted service is required.
