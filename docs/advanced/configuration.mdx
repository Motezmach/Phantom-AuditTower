# Configuration

Phantom reads environment variables and uses `~/.phantom/cli-config.json` for local interactive configuration. On Windows, `~` means the current user's profile directory.

The names below are the supported Phantom configuration surface. Secrets are never committed to the repository.

## Model and request settings

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_LLM` | required for API-key mode | Model identifier, for example `deepseek/deepseek-chat`. |
| `LLM_API_KEY` | unset | Provider key. `OPENAI_API_KEY` is accepted as an alias. |
| `LLM_API_BASE` | unset | OpenAI-compatible base URL. Aliases: `OPENAI_API_BASE`, `OPENAI_BASE_URL`, `LITELLM_BASE_URL`, `OLLAMA_API_BASE`. |
| `LLM_EXTRA_HEADERS` | unset | JSON object of additional provider headers. |
| `PHANTOM_REASONING_EFFORT` | `high` | `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, or `max`. |
| `PHANTOM_FORCE_REQUIRED_TOOL_CHOICE` | `false` | Request required tool use where the provider supports it. |
| `PHANTOM_PROMPT_CACHE` | `true` | Enable prompt caching where supported. |
| `LLM_DISABLE_STREAMING` | `false` | Disable streamed model responses. |
| `LLM_TIMEOUT` | `300` seconds | Overall model request timeout. |
| `LLM_STREAM_IDLE_TIMEOUT` | `300` seconds | Maximum idle time while receiving a stream. |
| `LLM_MAX_TOOL_CALLS_PER_TURN` | `32` | Tool-call limit for one agent turn. |

## Optional deduplication model

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_DEDUPE_MODEL` | unset | Separate model used for duplicate-finding review. |
| `PHANTOM_DEDUPE_REASONING_EFFORT` | unset | Reasoning effort for that model. |
| `DEDUPE_LLM_API_KEY` | unset | Key for the deduplication provider. |
| `DEDUPE_LLM_API_BASE` | unset | Base URL for the deduplication provider. |
| `DEDUPE_LLM_EXTRA_HEADERS` | unset | JSON headers for the deduplication provider. |

## Runtime and sandbox settings

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_IMAGE` | `phantom-sandbox:1.3.0` | Docker image used for tool execution. |
| `PHANTOM_RUNTIME_BACKEND` | `docker` | Runtime backend. Docker is the built-in backend. |
| `PHANTOM_SANDBOX_CPUS` | unset | Optional CPU limit, such as `2`. |
| `PHANTOM_SANDBOX_MEM_LIMIT` | unset | Optional memory limit, such as `4g`. |
| `PHANTOM_SANDBOX_SHM_SIZE` | Docker default | Optional shared-memory size. |
| `PHANTOM_SANDBOX_PIDS_LIMIT` | Docker default | Optional process limit. |
| `PHANTOM_DOCKER_SANDBOX_NETWORK` | Docker default | Attach the container to a named Docker network. |
| `PHANTOM_UPSTREAM_PROXY` | unset | Optional upstream proxy URL passed to the sandbox. |
| `PHANTOM_MAX_CONTEXT_IMAGES` | `3` | Maximum live image outputs retained per agent context; `0` disables retention. |
| `PHANTOM_SANDBOX_LOG_MAX_SIZE` | `50m` | Maximum size of one container JSON log file. |
| `PHANTOM_SANDBOX_LOG_MAX_FILE` | `3` | Number of rotated container log files. |
| `PHANTOM_CAIDO_ALLOWED_DOMAINS` | unset | Optional allowed-domain setting consumed by the sandbox entrypoint. |

## Diagnostics and update checks

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_DEBUG` | `false` | Enable debug logging for troubleshooting. |
| `PHANTOM_NO_UPDATE_CHECK` | unset/off | Disable the background update check. CI environments disable it automatically. |

## Context and integrations

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_CONTEXT_AUTO_COMPACT` | `true` | Compact long agent histories automatically. |
| `PHANTOM_CONTEXT_BUFFER_TOKENS` | `20000` | Context headroom before compaction. |
| `PHANTOM_CONTEXT_KEEP_TOKENS` | `8000` | History retained during compaction. |
| `PHANTOM_CONTEXT_FALLBACK_TOKENS` | `200000` | Fallback context threshold. |
| `PHANTOM_CONTEXT_SUMMARY_TOKENS` | `4096` | Maximum compaction summary size. |
| `PHANTOM_TOOL_OUTPUT_MAX_TOKENS` | `8000` | Tool-output token bound. |
| `PHANTOM_TOOL_OUTPUT_MAX_LINES` | `2000` | Tool-output line bound. |
| `PHANTOM_TOOL_OUTPUT_MAX_BYTES` | `51200` | Tool-output byte bound. |
| `PHANTOM_TELEMETRY` | `true` | Enable anonymous operational telemetry; set `false` to opt out. |
| `PERPLEXITY_API_KEY` | unset | Optional web-search integration. |
| `POSTMAN_API_KEY` | unset | Optional live Postman collection lookup. |

## Retired relay compatibility

The old email/cloud relay handlers are disabled by default and are not part of
the local Phantom workflow. They remain only for compatibility tests:

| Variable | Default | Purpose |
| --- | --- | --- |
| `PHANTOM_ENABLE_LEGACY_RELAY` | unset/off | Explicitly enable the retired relay endpoints. Do not set this for normal local use. |
| `PHANTOM_APP_URL` | empty | Relay base URL read only when the legacy flag is enabled. |

## Examples

PowerShell:

```powershell
$env:PHANTOM_LLM="deepseek/deepseek-chat"
$env:LLM_API_KEY="your-api-key"
$env:PHANTOM_IMAGE="phantom-sandbox:1.3.0"
$env:PHANTOM_RUNTIME_BACKEND="docker"
$env:PHANTOM_SANDBOX_CPUS="2"
$env:PHANTOM_SANDBOX_MEM_LIMIT="4g"
```

Bash:

```bash
export PHANTOM_LLM="ollama/qwen3-vl"
export LLM_API_BASE="http://localhost:11434"
export PHANTOM_IMAGE="phantom-sandbox:1.3.0"
```

Run-specific labels `PHANTOM_RUN_ID` and `PHANTOM_RUN_TYPE` are set by integrations that want Docker labels; they are not needed for a normal scan.
